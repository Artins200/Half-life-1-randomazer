# Half-Life 1: Randomizer Chaos Mod (Рандомайзер Хаоса + Счётчик смертей)

Готовый к игре одиночный мод для **Half-Life 1 (Steam / GoldSrc)** — как с обновлением **25th Anniversary**, так и на `steam_legacy`.

Каждые **10 секунд** в сюжетной кампании срабатывает случайное событие из пула **38 сбалансированных эффектов хаоса** — без нечестных ваншотов, мгновенных смертей и поломки сюжетных NPC. Прямо на внутриигровом **HUD** отображаются:
- **Несбрасываемый счётчик смертей** (сохраняется на диск в реальном времени — **не обнуляется** при загрузке автосейва, F6/F7 Quickload или перезапуске игры);
- **Таймер обратного отсчёта** с прогресс-баром до следующего события;
- **Название текущего события** и активные временные модификаторы + подробное описание на русском языке в чате/консоли.

---

## Быстрая установка (за 30 секунд — компиляция не нужна!)

В папке [`hl_randomizer/dlls/`](hl_randomizer/dlls/) уже лежат готовые скомпилированные библиотеки мода для **Windows (`hl.dll`)** и **Linux (`hl.so`)**.

1. Откройте корневую папку **Half-Life** в Steam:
   - В библиотеке Steam нажмите ПКМ по **Half-Life** → **Управление** → **Просмотреть локальные файлы**  
     *(обычно это `C:\Program Files (x86)\Steam\steamapps\common\Half-Life\`)*.
2. Скопируйте папку **`hl_randomizer`** из этого репозитория прямо внутрь папки `Half-Life/`, чтобы получилось так:
   ```text
   Half-Life/
   ├── valve/
   └── hl_randomizer/
       ├── dlls/
       │   ├── hl.dll
       │   └── hl.so
       ├── liblist.gam
       ├── autoexec.cfg
       ├── chaos.cfg
       └── commandmenu.txt
   ```
3. **Запуск мода** (любым из двух способов):
   - **Способ А (Параметры запуска — самый удобный):** в свойствах **Half-Life** в Steam укажите параметр запуска:
     ```text
     -game hl_randomizer
     ```
     и нажмите **Играть**!
   - **Способ Б (Через список модов):** полностью перезапустите клиент Steam — в вашей библиотеке появится пункт **«Half-Life: Randomizer Chaos»**.

## Что отображается на экране (HUD)

Мод использует нативные каналы текста движка GoldSrc (`TE_TEXTMESSAGE`), поэтому не требует замены `client.dll` и на 100% совместим с любыми сохранениями оригинальной кампании:

1. **Левый верхний угол (постоянная панель статуса):**
   ```text
   DEATHS: 4  (MAP: 1)  |  EVENTS: 27
   NEXT:  6.5s [######----]
   LAST: MOON GRAVITY
   ACTIVE: [LOW GRAV 11s] [FOV 122 8s]
   ```
2. **Верх по центру (баннер нового события):**
   Яркое всплывающее название сработавшего события с цветовой кодировкой (зелёный — бонус, голубой — физика/перемещение, пурпурный — безумие, оранжево-красный — опасность).
3. **Центр экрана при гибели:**
   Всплывающее оповещение `YOU DIED! TOTAL DEATHS: X` в момент смерти — счётчик мгновенно записывается в `hl_randomizer/chaos_stats.cfg` и `hl_randomizer/deaths.txt`, поэтому при загрузке последнего сохранения число смертей остаётся честным.
4. **Чат / консоль:**
   Полное название и описание каждого события **на русском языке**.

## Полный список 38 событий Хаоса

Все события спроектированы специально под прохождение сюжетной кампании Half-Life 1:
- **Никаких мгновенных убийств:** события, влияющие на здоровье или взрывную волну, никогда не опускают HP игрока ниже безопасного порога.
- **Защита сюжета:** до надевания костюма HEV в главе `c1a0` («Аномальные материалы») оружейные и опасные события автоматически блокируются, а сюжетные учёные и охранники с `targetname` защищены от телепортации и подбрасывания.
- **Умный спавн:** монстры проверяются по `TraceHull` и линии видимости, чтобы никогда не застревать в стенах или прямо в хитбоксе игрока.

## Консольные команды и настройки

Откройте консоль клавишей `~` (`Ё`) во время игры или отредактируйте файл [`hl_randomizer/chaos.cfg`](hl_randomizer/chaos.cfg):

| Команда / CVar | По умолч. | Описание |
|---|---:|---|
| `chaos_enabled 1` | `1` | `1` — включить рандомайзер, `0` — поставить на паузу |
| `chaos_interval 10` | `10` | Интервал между случайными событиями в секундах (от `2` до `300`) |
| `chaos_sound 1` | `1` | Звуковые сигналы отсчёта `3..2..1` и срабатывания событий |
| `chaos_ru_chat 1` | `1` | Выводить русские описания событий в чат |
| `chaos_now` | — | Немедленно запустить случайное событие прямо сейчас |
| `chaos_trigger <0..37>` | — | Запустить конкретное событие по его номеру (например, `chaos_trigger 11`) |
| `chaos_toggle` | — | Быстрое переключение паузы рандомайзера |
| `chaos_reset_deaths` | — | Сбросить счётчик смертей в `0` (также обновляет `chaos_stats.cfg` и `deaths.txt`) |
| `chaos_status` | — | Показать подробную статистику в чате и консоли |
| `chaos_list` | — | Вывести полный список всех 38 событий в консоль |

## Как устроена архитектура мода

Мод реализован как чистый 32-битный **прокси-модуль `hl.dll` / `hl.so`** для движка GoldSrc:
1. При запуске движок загружает `hl_randomizer/dlls/hl.dll`, который автоматически находит оригинальную `valve/dlls/hl.dll` вашей копии Half-Life 1 и объединяет таблицы экспортов PE (`IMAGE_EXPORT_DIRECTORY`) на лету.
2. Перехватываются `pfnFunctionFromName` и `pfnNameForFunction`, благодаря чему **штатные сохранения и загрузки Half-Life 1 (F6 / F7 / автосейвы между главами) работают на 100% без ошибок**.
3. Счётчик смертей независим от `.sav`-файлов движка: при каждой смерти он моментально сохраняется в `hl_randomizer/chaos_stats.cfg` и текстовый файл `hl_randomizer/deaths.txt`.

## Сборка из исходного кода (для разработчиков)

### Вариант 1: Windows (Visual Studio / CMake)
```powershell
cmake -B build-win32 -A Win32 -DCMAKE_BUILD_TYPE=Release
cmake --build build-win32 --config Release
# Готовый файл: build-win32\Release\hl.dll
```

### Вариант 2: Кросс-компиляция Windows `hl.dll` + Linux `hl.so` через Make + Zig C++
```bash
make all
make test
```

Также в репозитории настроен GitHub Actions workflow (`.github/workflows/build.yml`), который автоматически собирает Win32 `hl.dll` (MSVC), прогоняет симуляционные тесты всех 38 событий и публикует архив мода `hl_randomizer_chaos_mod.zip`.
